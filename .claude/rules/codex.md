# Codexにレビューと調査を頼む

持ち主はClaude Codeで開発し、Codexをレビューと調査の独立した判断者として使う。Codex側の規約はrootの
`AGENTS.md`（Codex専用。Claude Codeは読まない）にあり、「頼まれた範囲に答え、別のAIを起動しない」と書いてある。

## いつ頼むか

- PRごとにmergeの前。差分の独立レビュー
- 一次情報で決まらない判断、規範どうしが衝突したとき
- 既に入ったものを振り返るとき

## 頼み方

```bash
codex exec -s read-only --ephemeral - < <依頼文のfile> > <出力のfile> 2>&1
```

- Bashの`run_in_background`で投げ、完了の通知を待つ。1本で10〜15分かかる。途中で止めない
- モデルとeffortは渡さない。持ち主の`~/.codex/config.toml`に従う
- 依頼文はscratchpadに書き、次を入れる
  - 範囲: `git diff <base>..<head>`、または未commitの`git diff`と基準のcommit
  - 変更の要旨と、持ち主が決めたこと（指摘の対象にしないと書く）
  - 受け入れ条件
  - 返す形: 重い順、`file:line`、再現できる入力、確かさ（再現済み / 読んで確定 / 推測）。欠陥が無ければ無いと書く
  - 読むだけでfileを書き換えないこと
- **Claude側のreviewerの結論と自分の見立てを渡さない。**渡すと独立した判断ではなくなる

## 受け取り方

- 出力の`tokens used`の後に、最後の答えがもう一度出る。そこを読む
- 指摘は主張として扱う。コードか再現で裏を取り、直す前のコードで落ちるtestを書いてから直す
- 直したら、直した差分だけを範囲にして再レビューに出す
- 採らなかった指摘は、理由を1行ずつPR本文の「見送った指摘」へ残す
- 再レビューのたびに指摘が周辺の入力へ細っていき、受け入れ条件の違反が無くなったら、そこで止めてよい
